# Jarred's Skillset

Installation:

```bash
npx skills@latest add jarredbarber/skills
```

## Skills

### Workflow

- **execute** — execute issues that triage has marked ready-for-agent; counterpart to `/triage`.
- **briefing** — cross-project status briefing; pulls the live state of every active project from the sources each project declares.
- **handoff** — prepare a short handoff document so another agent can pick up your work.

### Documents

- **get-to-the-point** — reconstruct the argument hiding inside a complex document (paper, RFC, design doc, spec, tutorial, blog post, or AI slop).
- **technical-markdown** — Markdown style guide for technical documents with equations or diagrams.
- **youtube-librarian** — retrieve, clean up, and document a YouTube video into a summary, guided analysis, and annotated transcript.

### Meta

- **skill-me** — turn a vague agent-skill idea into a confirmed behavioral design, then build the skill.
- **adversarial-improvement** — advance one bounded curriculum step for an executable, measurable technical capability.
- **external-subagents** — augment internal subagents with models from other providers to unlock capabilities and save quota.
- **ponytail-tao** — the general form of ponytail: laziness-as-efficiency for any task, not just code.

## Rules

- **rules/adhd.md** — ADHD-friendly execution style for all projects.
